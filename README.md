# HACKBIOS

Welcome to the HackBios Rover project.

## Overview
This repository contains the source code for the HackBios Rover application.

## Getting Started

### Prerequisites
- Node.js and npm
- Git

### Installation
```bash
git clone https://github.com/adityasri2501/HackBios-Rover.git
cd HackBios-Rover
npm install
```

### Run the project
```bash
npm start
```

## Project Structure
- `src/` – application source code
- `public/` – static assets
- `package.json` – project scripts and dependencies

## Notes
This project is a TypeScript-based repository and is intended to support the HackBios Rover platform.
